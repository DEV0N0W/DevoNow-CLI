## Status definitions

- **ACCEPTED:** all required criteria have current, attested evidence for the release candidate.
- **NOT ACCEPTED:** validation ran but mandatory evidence is incomplete or a check failed.
- **PENDING:** the target or checklist is available but candidate validation has not run.
- **BLOCKED:** a necessary artifact, environment, account, or authorization is absent.
- **PREVIOUSLY ACCEPTED:** earlier environment accepted the scenario; the current candidate has not been revalidated.
