# @devn0w/devnow-agent-responses-api-proxy

<p align="center"><code>npm i -g @devn0w/devnow-agent-responses-api-proxy</code> to install <code>codex-responses-api-proxy</code></p>

This package distributes the prebuilt [DevoNow Responses API proxy binary](https://github.com/DEV0N0W/DevNow-CLI/tree/main/devnow-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/codex-responses-api-proxy.js --help
```

Refer to [`devnow-rs/responses-api-proxy/README.md`](https://github.com/DEV0N0W/DevNow-CLI/blob/main/devnow-rs/responses-api-proxy/README.md) for detailed documentation.
